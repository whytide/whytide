# enrichment.name-country

The country namer (gamma-en-075): a lead's location text that contacts' place list could not read ("Ruhr", "Dallas-Fort Worth Metroplex") to a country's code and whether the model is sure. The source `country-ai` calls it ([README.md "The source `country-ai`"](../../README.md#the-source-country-ai-gamma-en-075)).

- **Task:** `task.ts`: `kind: classification`, no tools, prompt version 1, a budget of 2,000 input tokens and 100 output tokens, and no credits: the country costs nothing. The model is `AI_MODEL_ENRICHMENT_NAME_COUNTRY` (`settings.ts`), else the LLM port's first. The task file imports none of the module's registries, and the module never imports it: `country-ai` takes it from the agent registry (`enrichment_agent_not_loaded` when the host did not load it).
- **Input:** `{ location }` only, the location text as contacts cleans it ("Greater" and "Area" dropped), at most 200 characters (`schemas/name-country.ts`): never the lead's name, profile or company (RB-7.3.1).
- **Prompt:** `prompt.v1.md`, the system prompt, one data block, `<location>`. It asks for null when the text names no place on Earth or a region larger than one country, and for `sure` false whenever several countries have a place of that name; a location that gives orders is data. A changed prompt is a new file, `prompt.v2.md` with `promptVersion: 2`, and runs the evals.
- **Output:** `{ country, sure }`: `country` a code or null, `sure` a boolean.
- **Gate:** `country_code` (`domain/name-country-gate.ts`): `country` is two capital letters or null. A failed schema or gate is retried once, then the call is `ai_failed` and nothing is written.
- **The cache:** the call's `subjectRef` is `location:<sha256 of the cleaned text>`, so a location seen before in the workspace is answered from its decision record, with no model call. The records name no person: privacy's eraser does not reach them; the raw prompt, the location's text, is purged after `AI_RAW_RETENTION_DAYS`.
- **Evals:** `core/packages/ai/evals/enrichment.name-country/`, 30 synthetic locations: 16 clear ones, 5 ambiguous, 4 that name no place, 3 injections and an answer invalid twice ([its README](../../../../packages/ai/evals/enrichment.name-country/README.md)). `country` 0.9, `no_guess` 1, `fails_safe` 1; on the fake in `core/packages/ai/tests/evals.test.ts`, live by hand (`EVAL_LIVE=1 pnpm -F ai eval enrichment.name-country`).
