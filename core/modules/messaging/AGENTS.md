# messaging: the brief for a coding agent

1. Read `README.md`, then `docs/concepts.md`, `docs/data.md`, `docs/flows.md`, `docs/security.md` and `docs/runbook.md`. They say what is true now and change in the same merge request as the behavior.
2. The rules: [coding](../../../docs/rules/coding.md), [security](../../../docs/rules/security.md), [delivery](../../../docs/rules/delivery.md). The shape of this folder is [architecture §4.2](../../../docs/architecture.md#42-inside-a-module): rules in `domain/` without a framework, Zod schemas in `schemas/`, NestJS in `api/`, Temporal in `workflows/`, agent tasks in `agents/` (importing `@whytide/ai`, never `@mastra/*`), Next.js in `ui/`, every screen string a key in `messages/en.json`, the registries in `permissions.ts`, `prices.ts`, `events.ts` and `settings.ts`, the tests in `tests/`.
3. Commands, from the repository root: `pnpm -F @whytide/messaging build`, `typecheck`, `test`, `lint`; `pnpm -F api test` for the routes; `pnpm -F web test` for the draft panel (`core/apps/web/tests/messaging-*.spec.ts`), whose `.tsx` the web's `typecheck` checks, not this module's.
4. The dossier reads other modules through their `index.ts` only; a value it does not list never enters it, and `tests/schema.test.ts` lists every field. Tests import `domain/`, `schemas/` and `testing/`, never `index.ts` or `api/`: Node cannot run the controller's decorators from source. Stay inside this folder; a change to a shared package is its own task.
5. A sequence step's draft (`kind = outbound_step`) changes only through approvals' path (beta-p3-020): alpha's routes refuse it (`step_draft_not_editable`), and the writer, `markFailed` and the sweep write a draft only while it is `drafting`. Never add a path that edits its text, and keep a failed or stuck draft without text (`tests/safety/`).
6. Every text that may be sent passes `checkText` (`domain/gates/check-text.ts`, beta-p3-020): the writer's answers through `checkWrittenText`, an edit (`editDraft`) and an approval (`approveStepDraft`) through `checkText` itself. A new path that stores or approves a text runs it too; never loosen a gate to make a test pass (`tests/safety/colleague-signal.test.ts`).
7. A step's draft approved without a person is approved by `approveStepDraftByMode` alone (gamma-p4-080), which runs `checkText` on the text and on the text with its channel's AI disclosure line, and freezes it with the line before the hash. Never add a path that approves without a person and without the line, never add the line on a person's approval, and never shorten or drop it to pass a gate (`tests/safety/disclosure.test.ts`).
