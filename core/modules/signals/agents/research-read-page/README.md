# signals.research-read-page

The page-reading agent (gamma-wr-046): for one page a research run read, what the page is and which companies it names, so that the run can look at each company's own site. [README.md "Web research"](../../README.md#web-research) says how a run uses it, [docs/security.md](../../docs/security.md) what the model may see.

- **Task:** `task.ts`: `kind: classification`, no tools, prompt version 1, a budget of 48,000 input tokens (20,000 characters of text and 100 links of 200 characters, in a script of three-byte characters, fit) and 8,000 output tokens (50 companies), and no credits (the run's cost is the cost event alone). A call over the budget is `ai_budget_exceeded`, which the read step counts as `reads_failed`. The model is `AI_MODEL_SIGNALS_RESEARCH_READ_PAGE`, else the LLM port's first. The task file imports none of the module's registries (index, events, ids, errors), and the module never imports it: hosts load it from the sources (core/packages/ai README "Declaring a task"), and `readPageCompanies` takes it from the agent registry.
- **Prompt:** `prompt.v1.md`, the system prompt. The data blocks, in order: `<source>` (the source's focus and region, scrubbed), `<place>` (what a page of the search's source type shows and what it is for, null for a page the member named) and `<page>` (its address without the query, its title, its text, scrubbed of links, email addresses and phone numbers and cut to 20,000 characters, and up to 100 of its links, none on LinkedIn or a social network). A page's words are data: an instruction in one is left out. The prompt asks for what the page is (`is`: `company_site`, `company_list`, `notice` or `other`) and for each company the page names its name as written, its link (only one of the page's links, null for a company's own site), its place, one line and the page's own words behind it, and never a person. A changed prompt is a new file, `prompt.v2.md` with `promptVersion: 2`, and runs the evals.
- **Schemas:** `schemas/research-read-page.ts`. The output: `is` and `companies`, at most 50, each `{ name, link, place, line, quote }`, the last four null when the page gives none.
- **Gates**, in code and after the call (`domain/research/read-checks.ts`), because each refuses a part of the answer and keeps the rest, which a task gate (the whole answer, asked again) cannot do. Each refusal is counted by the gate's name in the run's counts, `refused_<gate>`:
  - `name`: a company whose name is not in the page's title or text, or holds `@`;
  - `link`: a link that is not one of the page's links (those the page holds, its own address included), or is not a company's site (LinkedIn, a social network, a directory, a news or a job site, an IP literal); the company is kept with no link and then searched by its name;
  - `place`: a place that is not on the page;
  - `quote`: a quote that is not on the page, or is shorter than eight characters, or a line without its quote: both are dropped, the company is kept;
  - `contact`: a quote, a line or a place that holds an email address, a link or a phone number: nothing about a person is taken here;
  - `duplicate`: a company twice on a page (name as written, any case);
  - `extra`: a second company on a company's own site.

  A page the model calls `other` keeps no company. A company's own site is the page's own address: its domain is the page's, whatever link the model gives. Comparisons fold case, compatibility forms and whitespace.
- **Evals:** `core/packages/ai/evals/signals.research-read-page/`, seven synthetic cases of two made-up businesses in two countries and two languages (a distributor of chilled food in a Polish-speaking country and an installer of rooftop solar in a Spanish-speaking one): an exhibitors' list with links, an award notice that names two companies and no link, a company's own site, a news page that names none, a plain-text answer asked again (ok after two attempts), a forum page that tries to instruct the model (the fail-safe case: its answer never holds the company it asks for), and a members' page that names people besides a company. Each case names the companies a good model gives, so the same cases run live. The scorer's checks: `outcome`, `fails_safe`, `kind`, `grounded` (name, place, quote and link are the page's), `no_person`, `recall`, `precision`. On the fake they run in `core/packages/ai/tests/evals.test.ts` with `EVAL_LIVE` unset; live (`EVAL_LIVE=1`, by hand, billed) after a prompt change, the owner's.
