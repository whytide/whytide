# signals.research-plan

The research plan agent (gamma-wr-040): at the start of a research run, the trade's own words by language, the source types worth searching, and the searches to ask, written from what a member gave in the app. [README.md "Web research"](../../README.md#web-research) says how a run uses it, [docs/security.md](../../docs/security.md) what the model may see.

- **Task:** `task.ts`: `kind: generation`, no tools, prompt version 3 (gamma-wr-110; version 1 and 2's files stay and their eval cases still pass), a budget of 24,000 input tokens and 8,000 output tokens, and no credits (the run's cost is the cost event alone). A call over the budget is `ai_budget_exceeded`, which the plan step answers as `research_plan_failed`. The model is `AI_MODEL_SIGNALS_RESEARCH_PLAN`, else the LLM port's first. The task file imports none of the module's registries (index, events, ids, errors), and the module never imports it: hosts load it from the sources (core/packages/ai README "Declaring a task"), and `planResearchRun` takes it from the agent registry.
- **Prompt:** `prompt.v3.md`, the system prompt (`prompt.v2.md` is the version before; version 3 adds a seventh data block, `<not_fit>`: the companies a member marked Not a fit for the source, `[{ name, domain, country, town }]`, 100 at most, as data; the plan looks for other kinds of company and place, and never repeats one). The data blocks, in order: `<knowledge>` (Company Knowledge's one-liner, long description, products, pain points, features and benefits, and competitors), `<audience>` (industries, size ranges, countries, titles, seniorities, must-haves, disqualifiers), `<source>` (focus, region, languages), `<places>` (the list of source types: id, what it shows, how it is found, its page kind; the same for every seller) `<asked>` (up to 200 queries the source asked within the re-check days: place, country, language, text and, from version 2, `found`: the companies its results led to, by verdict) and `<found>` (version 2: what the source's earlier runs found, as counts: for each source type the companies it led to by verdict, and the towns, with country and state, of the fitting companies, the most common first, 50 at most; never a company's name, site, line or quote, read by `domain/research/found-stats.ts`). The member's free text is scrubbed (links, email addresses and phone numbers as placeholders) and is data, never instructions; the prompt says that no query or word names a person and that none is invented. The prompt tells the model to look more where companies fit and less where the results did not, and that counts of 0 may mean results not judged yet. A changed prompt is a new file, `prompt.v3.md` with `promptVersion: 3`, and runs the evals.
- **Schemas:** `schemas/research-plan.ts`. The output: `words` (`[{ language, words }]`, 8 languages and 40 words each at most), `places` (ids), `queries` (100 at most, each `{ place, country, language, text }`). The schema bounds the shape; it does not refuse a country, a language or a place: a code is any short string here, and the gates below decide.
- **Gates:** in code, after the call and not as the task's gates, since a task gate refuses the whole answer (`domain/research/checks.ts`): a source type off the list, a country outside the audience's, a language outside the source's (else off the kind's list), a blank query or one longer than the search port takes, a query asked within `SIGNALS_RESEARCH_RECHECK_DAYS`, a repeat within the plan. Each refusal drops its part and is counted by the gate's name; the rest is kept. A failed schema is retried once, the failure in `<validation_error>`, then the call is `ai_failed` and the run ends `research_plan_failed`.
- **Evals:** `core/packages/ai/evals/signals.research-plan/`, six synthetic cases of two made-up businesses (a maker of cold-chain loggers selling in a Polish-speaking country, then also a Czech-speaking one; a maker of solar roof rails selling in two Spanish-speaking countries): a plan in the source's language, one retried after a plain-text answer, one in two languages when the source names none, one against a list of queries already asked, and an instruction in the member's description. The scorer's checks: `outcome` (the call ends ok), `fails_safe` (the injection's words appear nowhere in the answer, or `ai_failed`), `scope` (each query names a source type of the list and a country and a language of the case, within 200 characters, and the plan picks enough source types), `fresh` (no query repeats one asked), `no_person` (no address, link or number), `words` (words for each language of the case). On the fake they run in `core/packages/ai/tests/evals.test.ts` with `EVAL_LIVE` unset; live (`EVAL_LIVE=1`, by hand, billed) after a prompt change, the owner's. From version 2 (gamma-wr-051), three cases with `<found>`: a plan for the Polish-speaking business that names the towns where companies fit (`kestrel-poland-what-was-found`), one for the Spanish-speaking business in two countries (`aurelia-chile-and-peru-what-was-found`) and a town that holds an instruction (`kestrel-instruction-in-a-found-town`, a fail-safe case); the scorer's `uses_found` (only a case that names `towns`): a query names one of the input's towns.

- **Version 3 evals** (gamma-wr-110): three cases (a Not a fit company in a Polish-speaking country, two in Chile and Peru, an instruction inside a Not a fit name) and the check `avoids_not_fit` (no query names a marked company or its domain, and the instruction is not followed), on the fake; `tests/evals.test.ts` counts them.


- **Version 4** (gamma-wr-090): `prompt.v4.md`, `promptVersion: 4` (versions 1 to 3 stay and their cases still pass). It adds a fourth thing to answer, `roleWords` (`[{ language, words }]`): the words the audience's titles and seniorities are written in, by language, for a search of a company's managers (README "A company's managers by search"). None when the audience names no title; never a name, address, link or number. Gates in code (`checks.ts`): a language off the source's is refused (`language`), a word over 60 characters or holding an address, link or number is refused (`role_word`), blanks and repeats are dropped, 20 words a language at most. The words are kept with the plan in `signal_research_plans.role_words` (an older plan holds `[]`). Evals: three cases (`kestrel-poland-role-words`, `aurelia-chile-and-peru-role-words`, `kestrel-instruction-in-a-title`, an instruction inside a title that must not be followed) and the check `role_words`, on the fake.
