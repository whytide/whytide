# docs/

The documents that live with the code. A module's own docs live in the module, under `core/modules/<name>/docs/`.

- [architecture.md](architecture.md): how Whytide is built, the one description.
- [rules/](rules/): the three files every change follows: [coding](rules/coding.md), [security](rules/security.md) and [delivery](rules/delivery.md).
- [adr/](adr/): the architecture decision records, one numbered file per decision, written from [0000-template.md](adr/0000-template.md):
  - [0001: Biome formats the code; the first toolchain pins](adr/0001-formatter.md)
  - [0002: the supply chain in alpha](adr/0002-supply-chain.md)

The research, the specifications and the task breakdown behind these documents live in a private planning repository.
